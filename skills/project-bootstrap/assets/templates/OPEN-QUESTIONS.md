# Open questions
Every unresolved question, in one place. When decided → ADR, delete the row. *Owner* is a person or role (the project owner by default). *Raised in* is a citation, or, for a question raised in conversation, the session and its date in prose. *Blocks* is a milestone or feature ID; before the roadmap exists, the design doc or the event ("the first deployment") that needs the answer.
