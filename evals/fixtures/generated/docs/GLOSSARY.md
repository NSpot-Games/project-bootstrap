# Glossary
Use these exactly — in docs, code, prompts, telemetry, conversation. New concept → new entry, same change.

## Notes
**Note** — one markdown file about one visit to a place (`docs/design/api-surface.md §2.1`).
**Index** — the derived grouping of notes by place, date and tag; never hand-edited (`docs/design/api-surface.md §2.2`).
**Golden example** — a folder of notes plus its expected index, run as a test (`docs/design/api-surface.md §4`).
**Place** — a slug grouping notes about one location; optional on a note.

## ID prefixes
| Prefix | Collection |
|---|---|
| `M<n>` | milestones |
| `M<n>-<nn>` | features and plans |

## Words we avoid
- **"post"** — say *note*.
- **"category"** — say *tag*.
