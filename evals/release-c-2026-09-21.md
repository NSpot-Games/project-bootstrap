Every assertion in the suite now passes against the current skill. The first-session run was
the cheapest of its three so far: with the plan template already in the project, the agent
copied it rather than reading the kit for the format.

## What each change did, as observed

- **Linter config and gitattributes.** Both were written without prompting, the tier pinned,
  and `.gitignore` gained the cache entry. The run also left `citation_exclude` empty because
  the project had no history folders, which is the right reading of the instruction.
- **Object templates in the project.** `tools/templates/` was copied verbatim; the first
  session used it for the plan; the project's workflow doc points at it instead of embedding a copy, so no
  run had to rewrite format hints into angle brackets any more.
- **README merge rule.** The run kept the existing README's pointer line and added the three
  sentences and the table rather than replacing the file.
- **Hook choice.** The agent noticed the kit was installed as a plugin and skipped the
  per-project hook, saying so in the final message. That was the audit's double-registration
  finding, closed.

## Open items this round surfaced

- **Citations to phase-start docs.** For the second time, a run cited
  `<project>/docs/design/versioning-and-compat.md` (a doc the profile schedules for a later
  phase) and had to reword it: generation does not create it, so after generation it is `E001`.
  The forward-citation warning covers files the bootstrap creates, not files a later phase
  creates. Either the profile should say not to cite phase-start docs by path until they exist,
  or the linter should treat a path listed in the profile's design-doc table as a warning until
  the file appears. Not decided here.
- **Fixture design docs predate release B.** The `after-roadmap` and `generated` fixtures'
  design docs carry no pointer line to the open-questions file, since they were written before
  that rule existed. No assertion depends on it, but the fixtures should be brought in line the
  next time they are regenerated.
