## What the runs showed beyond the numbers

- **The one compliance violation from the audit reproduced exactly.** With the profile outline
  as it stands, the agent wrote an in-doc open-questions section. The fix is in the profiles,
  not in the agent.
- **Agents already improvise most of release B correctly, once.** The docs-rich run used the
  vision docs as brainstorm input and surfaced the planted contradiction; the first-session run
  flipped the milestone to `in progress` and called it a judgement call; the generation run
  inlined the ADR template because the pointer to `assets/templates/adr.md` would not resolve in the project, left no stubs, and cited the
  layers rule for it. Release B's job is to make these reliable and specify their outputs, not
  to enable them.
- **Forward citations are the mid-bootstrap pain.** The git run's own lint reported seven
  `E001` for docs that later sessions create; the one-design-doc run angle-bracketed the same
  paths to dodge the check; the generation run wrote a `citation_roots` config so quoted note
  paths resolve. Three runs, three workarounds for one gap: an agent has no sanctioned way to
  cite a file the procedure will create later.
- **The generation run replaced the template's format hints by hand.** `{{date}}T{{hh}}:{{mm}}Z`
  and the embedded plan and milestone templates in `<project>/docs/WORKFLOW.md` had to be rewritten in angle
  brackets to pass `E005`. Every run that generates will repeat this until the template ships
  them that way (release C).
- **Cost.** A single-step scenario runs 70k to 130k tokens; the compressed full bootstrap ran
  170k and thirteen minutes. Twelve runs per iteration (six scenarios, two skill versions) is
  the budget to plan for.

## Harness corrections made during the baseline

- The agent's final message is written inside the project (the only directory it may touch)
  and moved out before grading; earlier it was linted as a project file.
- The git scenario's prompt now includes the brainstorm, so the run reaches a commit.
