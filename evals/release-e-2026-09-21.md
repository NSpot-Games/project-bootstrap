## The 31 improvisations

The count went up from 24 because the agent reported finer grain, not because the procedure
left more undecided: none of the 31 is a decision that changed what the run produced, and none
lacks a section to live in. Sixteen were folded into the skill during the run, each in its own
commit (the forward-citation grace covering the example instance folder; one numbered heading
per section; a gap that is both folded and held; the import source beside the instance; a row
that blocks an event rather than a doc; where a decided row says so; a later doc extending the
schema; unset numbers as marked recommendations; exits and feature lines held in the scratch
list; the sketched second phase; the feature-count rule at the roadmap step; a backfilled ADR's
body; a two-marker entry; the next milestone's dependency; the README's name as codename; what
to lead with when there are no contradictions; the glossary's ID table; `M0-01` claimable
first). Two were acted on after the run: the gitattributes file moves into the first commit,
and the profile outlines no longer ask for a separate "decisions we're committing to" list now
that the Decisions section is mandatory.

**Remaining clarifications (11)**, each a sentence if wanted: whether to ask up front if the
real instance can be obtained; the stack recorded in the primary doc before any doc rests on it;
assumed rows marked in a capability table; where the line falls between the architecture doc's

**Not gaps (2)**: reading the SHA from the log rather than rev-parse; shell heredoc failures.

## Where this leaves the kit

Five releases on from the audit. The linter is trusted and its warnings are all expected ones.
The procedure is followed rather than improvised across: three full runs of the same project
went from 57 improvisations with 15 real gaps, to 24 with 4, to 31 with none. The remaining
list is grain, not gaps. The scenarios take minutes and a full run takes half an hour, so the
next change to the skill, whatever it is, can be measured the same way.
